# Template & Quality Rules

## Template Lock

- Visual frame is locked to the Xiaomi dense template style.
- Keep section order, spacing rhythm, and layout proportions stable.
- Replace content only; do not redesign structure.

## Required UI Blocks

- Core Diagnosis / KEY INSIGHT
- Platform Compare
- Top Conversation Topics
- High-Value Prompts
- Existing Strengths
- Missing Trust Assets
- Sentiment Structure
- Top Citing Domains ⭐
- Footer with Brand AI Performance Check / By Dageno AI

## Logo Rules

- Top-left brand logo must render.
- Competitor logos must render from domain favicon source.
- If image fails, fallback initials must appear.

## Density Rules

- Keep information dense and readable.
- Avoid large blank areas and avoid content overlap.
